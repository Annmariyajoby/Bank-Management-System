# 🏦 Bank Management System

A **Java-based Bank Management System** developed using **Java Swing**, **JDBC**, and **MySQL**. This desktop application provides secure and efficient banking services, allowing users to perform transactions while enabling administrators to manage customer accounts and monitor banking activities.

---

# ✨ Features

## 👤 Customer Features

* 🔐 Secure User Login
* 📝 Multi-Step Account Registration
* 💰 Deposit Money
* 💸 Withdraw Money
* ⚡ Fast Cash Withdrawal
* 💳 Balance Enquiry
* 📄 Mini Statement
* 🔑 Change ATM PIN
* 📊 Transaction History

## 👨‍💼 Administrator Features

* 🔒 Secure Admin Login
* 📋 Admin Dashboard
* 👥 Manage Customer Accounts
* 📈 Monitor Banking Operations

# 📁 Module Description

| 📄 File                       | 📌 Description                                           |
| ----------------------------- | -------------------------------------------------------- |
| 👨‍💼 **AdminDashboard.java** | Administrator dashboard for managing banking operations. |
| 🔐 **AdminLogin.java**        | Secure login page for administrators.                    |
| 💳 **BalanceEnquiry.java**    | Displays the customer's current account balance.         |
| 🔗 **Conn.java**              | Establishes the JDBC connection with the MySQL database. |
| 💰 **Deposit.java**           | Allows customers to deposit money into their account.    |
| ⚡ **FastCash.java**           | Enables quick cash withdrawals using predefined amounts. |
| 👤 **Login.java**             | Customer login page.                                     |
| 📄 **MiniStatement.java**     | Displays recent account transactions.                    |
| 🔑 **PinChange.java**         | Allows customers to securely change their ATM PIN.       |
| 📝 **Signup.java**            | First step of customer registration.                     |
| 📋 **SignupTwo.java**         | Second step of customer registration.                    |
| ✅ **SignupThree.java**        | Final step of account creation.                          |
| 🧪 **TestConnection.java**    | Verifies the database connection.                        |
| 💼 **Transaction.java**       | Main transaction menu for banking services.              |
| 💸 **Withdrawal.java**        | Allows customers to withdraw money from their account.   |

# 🚀 How to Run

## ✅ Prerequisites

* ☕ Java JDK 8 or above
* 🗄️ MySQL Server
* 🔗 JDBC MySQL Connector
* 💻 NetBeans / Eclipse / IntelliJ IDEA

## ▶️ Installation Steps

### 1️⃣ Clone the Repository

```bash
git clone https://github.com/your-username/BankManagementSystem.git
```

### 2️⃣ Open the project in your preferred Java IDE.

### 3️⃣ Create the required MySQL database and tables.

### 4️⃣ Update your database credentials in:

```text
Conn.java
```

### 5️⃣ Run:

```text
TestConnection.java
```

to verify the database connection.

### 6️⃣ Finally, run:

```text
Login.java
```

to launch the application.
